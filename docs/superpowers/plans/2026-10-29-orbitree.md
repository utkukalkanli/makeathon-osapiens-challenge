# Orbitree Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Orbitree, a static, scroll-story web app that puts our deforestation labels and model predictions on a realistic 3D MapLibre globe, deployable to Vercel.

**Architecture:** A one-off Python pipeline (`tools/web_data/`) turns the public challenge labels (3.9 MB) and our 9 submission GeoJSONs into small static files under `web/public/data/`, which are committed. A Vite + React + TypeScript app (`web/`) renders a MapLibre globe whose camera and layer visibility are driven by declarative chapter configs. Scroll position picks the active step. After the last chapter, an explore panel takes over. There is no backend.

**Tech Stack:** Python 3.11 (rasterio, numpy, shapely, pyproj, pillow, requests, pytest) · Node 24, Vite, React 18, TypeScript, maplibre-gl ≥ 5, vitest.

**Spec:** `docs/superpowers/specs/2026-10-29-globe-showcase-design.md`

## Global Constraints

- App name **Orbitree**; title rendered as `Orbi·tree` or `OrbiTree` style split. Tagline: "from orbit to every tree".
- All UI copy in English.
- No overclaiming: never say our model is "right"/"correct"/"the truth" on test tiles. Performance numbers are only: val F1 0.763, val IoU 0.622 (final model `temporal_s2s1_norm_pseudo_v1`), and optionally leaderboard Union IoU 40.29% (labelled as the earlier `s2s1_norm_v1` model).
- Credits visible: "osapiens Terra Makeathon 2026", "Built by Utku Kalkanlı", and a repo link.
- Attributions visible (MapLibre attribution control): Esri imagery "Imagery © Esri, Maxar, Earthstar Geographics, and the GIS User Community"; GFW "Alerts © Global Forest Watch (UMD GLAD, WUR RADD)"; tree cover loss "Hansen/UMD/Google/USGS/NASA"; labels "Weak labels: GLAD-S2, GLAD-L, RADD via osapiens Terra Makeathon 2026".
- maplibre-gl major version ≥ 5 (globe projection). No backend, no env vars, no Supabase.
- `web/public/data/` total < 30 MB. The opening chapter fetches only `tiles.json` and `models.json`.
- Label thresholds exactly as `src/labels.py` (GLAD-S2 ≥ 3 and date > 731; GLAD-L ≥ 2 for years 21–25; RADD conf ≥ 2 and days > 2192). Reuse those functions; don't reimplement them.
- Featured model id: `temporal_s2s1_norm_pseudo_v1_thr040`.
- Colours: our model `#22d3ee` (cyan); GLAD-S2 `#facc15`; GLAD-L `#fb923c`; RADD `#f43f5e`; agreement ramp 1 source `#fde68a`, 2 sources `#f97316`, 3 sources `#dc2626`; train pins `#4ade80`; test pins `#f87171`.
- Primary target is desktop/projector ≥ 1280 px wide. Below 768 px the story stacks (globe on top, text below) without breaking.

## Review Focus

1. **External tiles fail or are slow (venue Wi-Fi, Esri/GFW outage):** the globe still renders with a dark ocean/land fallback and the story keeps working; a failed raster tile never throws or blanks the app. → Task 4 test `basemap falls back to EOX after repeated Esri errors`.
2. **Fast scroll or scrolling back up:** the camera and layers settle on the *currently* active step, not on a stale earlier `flyTo`. → Task 6 test `pickActiveStep returns the step nearest the viewport anchor` plus the `cameraFor` determinism test.
3. **User drags the globe mid-story, then scrolls:** auto-rotate stops on first interaction, and the next step still flies to its configured camera. → Task 4 test `autoRotate stops after user interaction`.
4. **A model with zero polygons in a tile** (e.g. the featured model has 0 in `47QMA_6_2`): the explore panel shows "0 ha" and the tile still flies; nothing errors. → Task 8 test `formatHectares(0) === "0 ha"` plus the `tileHectares` missing-key test.
5. **No WebGL / narrow screen:** with no WebGL, a readable message replaces the map and the story text still renders. Below 768 px the layout stacks. → Task 9 manual verification steps.

  - `tile_grid(bounds: tuple[float,float,float,float], size: int = 1000) -> tuple[tuple[int,int], Affine]`: EPSG:4326 grid over `(w,s,e,n)`; shape `(size, round(size*(e-w)/(n-s)))`, via `rasterio.transform.from_bounds`.

Percentages are 0–100, rounded to 1 dp. `*SourcePct`/`allAgreePct` are relative to alerted pixels (votes ≥ 1). Per-source pct is relative to all pixels. All zero when nothing is alerted.
  - `assign_tile_ids(fc: dict, tiles: dict[str, shapely.Polygon]) -> dict`: returns a new FeatureCollection; each feature gets `properties.tile_id` (the tile containing its `representative_point()`, else `None`).
  - `hectares_by_tile(fc: dict) -> dict[str, float]`: geodesic area (pyproj `Geod(ellps="WGS84")`) summed per `tile_id`, in ha, rounded to 1 dp.
  - `simplify_fc(fc: dict, tolerance: float = 0.00003, precision: int = 6) -> dict`

**Interfaces:**
- Produces:
  - `cameraFor(target: CameraTarget, tiles: Tile[]): Camera`. For `{tileId}`: center = tile center, zoom default 12.2, pitch default 0, bearing default 0. Throws on an unknown tile id.
  - `pickActiveStep(rects: { id: string; top: number; bottom: number }[], anchorY: number): string | null`: the step whose box contains `anchorY`; otherwise the nearest one; `null` if the list is empty.
  - `CHAPTERS: Chapter[]` with chapter ids `opening`, `disagree`, `approach`, `unseen`, `explore`, in that order.
    - `opening`: one step, camera `{center:[10,12], zoom:1.6, pitch:0, bearing:0}`, `autoRotate: true`, layers `{pins:true}`.
    - `disagree`: steps `disagree-agreement` (labels.agreement, labelTiles `[DISAGREE_TILE]`), `disagree-sources` (glads2 + gladl + radd on, agreement off). Camera `{tileId: DISAGREE_TILE}`. `DISAGREE_TILE` is the const recorded in Task 2.
    - `approach`: one step, camera `{tileId: DISAGREE_TILE, zoom: 9}`, labels.agreement on.
    - `unseen`: steps `unseen-colombia` (`18NYH_2_1`), `unseen-cameroon` (`33NTE_5_1`), `unseen-cambodia` (`48PWA_0_6`); each has `prediction:true`, `gfwAlerts:true`. Skip `47QMA_6_2` in the story because the featured model has 0 polygons there.
