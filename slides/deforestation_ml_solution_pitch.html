Slide 02

The Challenge

We need to detect post-2020 deforestation across multiple geographies, despite noisy labels, missing observations, cloud contamination, and limited training data.

Why this is hard

Observational noise

  • Optical imagery suffers from cloud cover and varying seasonal visibility
  • Radar is more robust to clouds but can be harder to interpret directly
  • Different regions have different appearance, sensor coverage, and land-use dynamics

Supervision noise

  • Labels come from alert systems, not fully verified dense annotations
  • Different alert products disagree in both space and time
  • Some changes are visible to one modality but not another
The solution must be robust, not just accurate on a narrow subset of tiles.
Slide 03

Data Strategy

Instead of relying on a single sensor or a single label source, the solution creates a shared representation from multiple modalities and a more reliable target from multiple weak label products.

Multimodal fusion

AEF embeddings

Provide compact semantic priors, so the model learns change patterns rather than basic land-cover semantics from scratch.

Sentinel-2

Supplies optical vegetation and burn-related signals through NDVI and NBR.

Sentinel-1

Adds cloud-robust radar evidence through annual VV ascending and descending composites.

Weak alerts

GLAD-S2, GLAD-L, and RADD are fused so no single noisy source dominates the target.

Why this matters

This design directly supports better reasoning, better use of data, and better robustness under noisy conditions, which are all central to the evaluation criteria.

Shared grid + multimodal features + fused weak supervision.
Slide 04

Model Design

The main algorithm is temporal change segmentation. It predicts a probability map of deforestation by comparing what was there before, what is there now, and how the signal evolved over time.

Design, reasoning, and use of data

Siamese path

  • Compares a pre image and a post image
  • Uses shared encoding for both timesteps
  • Focuses on explicit change through [post, |post - pre|]
  • Useful as a strong, simple baseline and as an ensemble member

Temporal path

  • Uses the full yearly series instead of only two dates
  • Combines last state, peak deviation, and average deviation over time
  • Better captures sustained forest loss versus temporary fluctuations
  • Especially helpful when one year is cloudy or incomplete

Algorithm intuition

The model is not asking "what class is this pixel?" in isolation. It is asking "did this pixel undergo a stable forest-loss-like transition across time and modalities?"

This is the main answer to "model design, reasoning, and use of data."
Slide 05

Handling Noisy Labels and Imagery

The solution is built to be noise-aware at both the target level and the input level.

Noise robustness
Target

Label fusion

Multiple weak alert products are combined by majority vote, which reduces dependence on any single noisy source.

Target

Soft supervision

The agreement rate between label sources can be used as a softer target instead of a strict binary one.

Input

Validity masks

The model explicitly sees whether S2 or S1 information is missing at a pixel.

Input

Modality dropout

During training, modalities are randomly removed so the network learns to remain stable under missing data.

Input

Radar support

Radar helps recover evidence in cloudy tropical regions where optical imagery alone is unreliable.

This slide directly addresses "handling of noisy labels and imagery."
Slide 06

Generalization Across Regions

A strong model should not overfit to one geography, one season, or one sensor condition. The solution therefore emphasizes cross-region robustness by design.

Cross-region robustness

Representation choice

AEF embeddings provide a semantically richer and more transferable starting point than raw pixels alone.

Temporal reasoning

Comparing trajectories rather than static appearance helps reduce regional appearance bias.

Radar inclusion

S1 improves robustness in cloud-prone regions such as tropical areas where optical views can fail.

Training strategy

  • Augmentation increases invariance to orientation and local layout
  • Positive crop sampling prevents the model from collapsing to easy all-negative predictions
  • Validation is done on held-out tiles from distinct contexts

Expected outcome

  • More stable behavior across continents and land-cover contexts
  • Lower dependence on a single sensor regime
  • Better transfer from the small train set to the hidden test distribution
This is the direct answer to "generalization across regions."
Slide 07

Pseudo Labels as the Improvement Loop

Pseudo labeling turns the test-distribution unlabeled data into additional training signal, but only where multiple teachers agree with confidence.

Teacher-student refinement

1. Train teachers

Train strong base models, ideally with complementary error patterns.

2. Predict test tiles

Generate dense probability maps on the unlabeled target distribution.

3. Keep only reliable pixels

Use confidence and agreement thresholds to define positive, negative, and ignore zones.

4. Retrain

Mix real labels with pseudo labels and train a stronger student model.

Why it is safe

  • Only agreed, confident pixels are trusted
  • Disagreement regions are masked out instead of forced
  • This reduces self-training collapse

Why it is powerful

  • It adapts the model to the test distribution
  • It increases effective supervision without manual labeling
  • It usually improves both recall and robustness
This is a strong answer to both "handling noise" and "generalization."
Slide 08

Quantitative Performance and Scalability

The solution is designed not only to perform well, but also to scale operationally.

Performance + scalability

Performance side

  • Validation uses full-tile inference, not only crop-level accuracy
  • Threshold sweeps allow operating-point tuning for the final task
  • Ensembling siamese and temporal teachers can improve stability

Scalability side

  • Annual feature composites reduce raw data volume
  • Sliding-window inference supports large tiles
  • Cached probability maps make threshold selection cheap
  • Pseudo-label reuse avoids recomputing the entire pipeline repeatedly

Computation

Feature caching and tile-wise processing help keep the pipeline practical.

Deployment fit

The same algorithmic structure works for both validation and full test inference.

Submission fit

The output is already aligned with polygon generation and time-step estimation.

This slide answers "quantitative performance and scalability."
Slide 09

Interpretability and Presentation Quality

A good hackathon solution should be understandable, inspectable, and easy to explain to both technical and non-technical reviewers.

Clarity and interpretability

Probabilities, not only labels

The model produces probability maps, which support calibration, threshold tuning, and uncertainty reasoning.

Time-step estimation

Polygon-level event timing can be tied back to NDVI drops, which gives a simple ecological explanation.

Readable experiment progression

Each experiment family reflects one modeling decision: add S2, add S1, normalize, pseudo-retrain, ensemble.

Presentation principle

The model should be explained as a sequence of decisions: shared grid, multimodal features, temporal change modeling, noise-aware supervision, and pseudo-label refinement. That story is easier for judges to follow than a long list of engineering details.
