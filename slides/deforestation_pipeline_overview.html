Slide 02

Problem and Expected Output

The task is to detect post-2020 deforestation from satellite data. The final output is not only a pixel mask, but a polygon-based GeoJSON submission.

Weak supervision + multimodal fusion

Main goal

  • Find deforestation signals from 2021 onward
  • Fuse heterogeneous and noisy data sources in one common space
  • Deliver the result as polygon-based GeoJSON
  • If possible, estimate a time_step for each polygon

Why it is hard

  • S2 is affected by clouds, while S1 is coarser but cloud-robust
  • The labels are weak alert sources, not clean ground truth
  • The number of train tiles is small
  • Representation learning and pseudo-labeling therefore matter a lot
The repo converts final prediction rasters into GeoJSON polygons.
Slide 03

Data Sources

The pipeline combines four ingredients: Sentinel-2, Sentinel-1, AlphaEarth Foundations embeddings, and weak alert labels.

S2 + S1 + AEF + GLAD/RADD

Sentinel-2

Monthly optical imagery. In this repo, annual median composites are turned into NDVI and NBR features.

Sentinel-1

Monthly radar imagery. Annual median VV ascending and VV descending in dB are used as features.

AEF

64-channel embedding. It provides a learned representation instead of raw pixels.

Weak labels

GLAD-S2, GLAD-L, and RADD are fused by majority vote.

Repository layout

data/makeathon-challenge/sentinel-2/ data/makeathon-challenge/sentinel-1/ data/makeathon-challenge/aef-embeddings/ data/makeathon-challenge/labels/train/

Key point: every modality is reprojected onto the AEF grid.
Slide 04

Feature Engineering on the AEF Grid

The pipeline first brings every modality onto the AEF reference grid, then builds a fixed-channel tensor.

Reference grid: AEF EPSG:4326

1. Reference

Each tile starts from the AEF grid.

Labels and features are aligned to this shared space.

2. S2 features

Monthly L2A files are cloud-masked and aggregated into annual median NDVI and NBR.

3. S1 features

Annual median VV ascending and VV descending in dB are computed.

4. Stack

64 AEF + 2 S2 + 2 S1 = 68 channels

Then normalization and validity masks expand it to 71 channels.

Raw stack

68

64 AEF embedding + 2 NDVI/NBR + 2 VV dB

Add masks

+3

S2 valid, S1 ascending valid, S1 descending valid

Final input

71

Z-score normalization + mask-aware neutral zero handling

That is why temporal_s2s1_norm_v1_best.pt uses in_channels = 71.
Slide 05

Siamese and Temporal U-Net Paths

The main model family is a change-detection U-Net. The key difference is whether it uses a pre/post pair or the full multi-year series.

src/unet/

Siamese model

  • Uses the pair pre = 2020 and post = 2025
  • The same encoder is applied independently to both images
  • Fuse rule: [post, |post - pre|]
  • Examples: siamese_unet_v1, siamese_s2_v1

Temporal model

  • Uses the full series 2020..2025
  • Temporal fusion is last + max diff + mean diff
  • Helps separate persistent change from temporary disturbances
  • Examples: temporal_v1, temporal_s2_v1, temporal_s2s1_norm_v1

Quick way to read experiment names

temporal = full multi-year series siamese = pre/post pair s2 = AEF + S2 s2s1 = AEF + S2 + S1 norm = z-score + valid masks

The repo uses full-tile sliding-window prediction for both training-time validation and inference.
Slide 06

Training Loop and Label Construction

Labels come from weak-source fusion, while the training loop is strengthened with crop sampling, augmentation, and modality dropout.

src/labels.py + src/unet/train.py

Label side

  • GLAD-S2, GLAD-L, and RADD are reprojected onto the same grid
  • hard label: positive if at least 2 of the 3 sources vote positive
  • soft label: agreement score, namely 0 / 1/3 / 2/3 / 1

Training side

  • Positive crop sampling reduces class imbalance
  • Rotation and flip augmentation are used
  • Modality dropout simulates missing S2 or S1 input
  • Loss: masked BCE + Tversky

Validation

Macro F1 and IoU are measured on fixed validation tiles using full-tile inference.

Checkpoint

The best macro F1 epoch is saved as checkpoints/*_best.pt.

History

Epoch-level train loss and validation metrics are stored in *_history.json.

Example: checkpoints/temporal_s2s1_norm_v1_history.json
Slide 07

Pseudo-Labeling and Retraining Loop

This is the current active phase: teacher models predict on test tiles, reliable pixels become pseudo labels, and then the model is trained again with pseudo-labeled data.

src/pseudo_labels_v2.py
Step 1

Teacher inference

temporal_s2_pseudo_v1 and temporal_s2s1_norm_v1 write cached probability maps on test tiles.

Step 2

Agreement filtering

If both teachers are confident, the pixel becomes pos or neg; otherwise it becomes ignore.

Step 3

Pseudo files

Each tile stores hard, weight, and prob.

Step 4

Masked training

Pixels with weight = 0 are ignored by the loss.

Step 5

Retrain

Real train crops and pseudo crops are mixed together. The new checkpoint family becomes *_pseudo_v1.

Why it helps

  • It makes training data look more like the test distribution
  • It transfers the shared confidence of the teacher models
  • It reduces punishment where S1 helps but weak labels are incomplete

Repository artifacts

pseudo_v2/*.npz checkpoints/temporal_s2s1_norm_pseudo_v1_best.pt submission/temporal_s2s1_pseudo_v1_*

Presentation line: "We generate pseudo labels with a teacher ensemble and retrain the student with pseudo-labeled data."
Slide 08

Clay Branch: Pretrained Encoder Path

The second model family in the repo is a siamese segmentation branch built on top of the Clay v1.5 encoder. This path uses more raw spectral input than the AEF embedding path.

src/clay/

Clay data loader

  • Builds 12-band S2 + 1-band S1 VV on the same AEF grid
  • Uses a two-timestep pre / post layout
  • Generates lat/lon metadata from the tile centroid

Clay model

  • The pretrained Clay encoder is frozen by default
  • The same siamese fusion idea is used: [post, |post - pre|]
  • Note: the loader contains S1, but the encoder path is mainly S2, while radar is used more strongly in the main U-Net pipeline

Frozen phase

checkpoints/clay_frozen_v1_best.pt

Fine-tune phase

checkpoints/clay_ft_v1_best.pt

Pseudo support

The Clay branch can also retrain with pseudo crop datasets.

Message: the Clay branch is the pretrained spectral-encoder experiment that sits next to the main U-Net path.

Slide 10

Submission Generation and Time-Step Estimation

At the end, the trained model produces probability rasters; then thresholding, polygonization, and time-step estimation produce the final GeoJSON.

src/submit_v2.py

1. Inference

A test tile is processed with TTA, and the probability map is cached.

2. Threshold

Multiple thresholds are tried, such as thr015 and thr020.

3. Polygonize

The binary raster is converted into polygons, and very small areas are removed.

4. Time step

A likely YYMM event time can be assigned from the monthly NDVI drop.

Cache logic

Folders such as submission/temporal_s2s1_norm_v1_cache/probs let us sweep thresholds without rerunning inference.

Presentation line

"We convert the prediction raster into polygons, then estimate the most likely event month from the S2 NDVI time series."

Slide 12

One-Slide Takeaway

The main idea of the repo is to combine strong learned representations with pseudo-labeling, so that a small amount of train data still produces better deforestation maps.

Closing

1. Common space

S2, S1, AEF, and weak-label sources are aligned on the AEF grid.

2. Two model paths

The U-Net change-detection path and the Clay pretrained-encoder path run side by side.

3. Iterative improvement

Teacher models generate pseudo labels, and pseudo-assisted retraining strengthens the student model.

One-sentence summary

"In this project, we first fuse multimodal features on the AEF grid, then explore U-Net and Clay-based model families, and finally improve the system with pseudo labels generated from teacher-model agreement."
