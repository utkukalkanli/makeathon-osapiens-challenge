# Deforestation Detection — Full Technical Writeup

**Challenge**: osapiens Terra Makeathon 2026 — pixel-level deforestation detection from multimodal satellite imagery for EU Deforestation Regulation (EUDR) compliance.

**Goal**: Predict which pixels were deforested (post-2021), output as GeoJSON polygons, evaluated by Union IoU.

---

## 1. Dataset

### 1.1 Modalities

Three independent data sources are provided per tile:

#### Sentinel-2 (S2) — Optical
- Monthly multispectral imagery, 12 bands (B01–B12), 10 m resolution
- Resampled and reprojected to AEF reference grid (EPSG:4326)
- **Cloud contamination is a major issue**: tropical regions can have only 1–3 clear months per year
- From each available year's worth of monthly images, we compute **annual cloud-masked NDVI and NBR composites** (pixel-wise median across cloud-free months)
  - **NDVI** = (B08 − B04) / (B08 + B04): green vegetation density
  - **NBR** = (B08 − B12) / (B08 + B12): biomass / burn ratio
- Cloud masking rule: `B02 < 2000` (blue reflectance < 0.20 implies clear sky)

#### Sentinel-1 (S1) — SAR Radar
- Dual-orbit VV polarization RTC (radiometrically terrain corrected), float32 dB scale
- Two independent orbit tracks: **ascending** and **descending** (different look angles)
- **All-weather, day/night** — S1 is not affected by clouds or darkness
- Annual median composites per orbit separately → `VV_ASC` and `VV_DESC`
- Typical values: −12 to −5 dB for forest, higher (less negative) for bare soil
- Coverage varies: descending orbits cover ~63% more valid pixels than ascending on average

#### AEF (AlphaEarth Foundation) Embeddings
- **64-dimensional learned feature vector per pixel**, computed annually
- Derived from a large foundation model pre-trained on global S1+S2 time series
- Encodes rich semantic priors (vegetation type, land use, texture, phenology) without requiring us to tune the backbone
- Grid aligned to EPSG:4326 at ~1004×998 pixels per tile, serving as the reference coordinate system for all other modalities

### 1.2 Labels (Weak Supervision)

All labels are **weak** — generated by third-party alert systems, each with its own blind spots and confidence schemes. No clean hand-annotated ground truth exists.

| Source | Derived from | Confidence encoding | Threshold used |
|--------|-------------|---------------------|----------------|
| **GLAD-S2** | Sentinel-2 monthly | 0–4 (0=none, 1=recent, 2=low, 3=medium, 4=high) | ≥ 3 |
| **GLAD-L** | Landsat annual | 0=none, 2=probable, 3=confirmed (per-year file) | ≥ 2 |
| **RADD** | Sentinel-1 radar | `confidence × 10000 + days_since_2014-12-31` | confidence ≥ 2 |

Each source has a `alertDate` encoding the approximate detection date. Labels cover alerts from **2021 onward** (epoch cutoffs: GLAD-S2 > day 731 since 2019-01-01; RADD > day 2192 since 2014-12-31; GLAD-L years 21–25).

**Fusion strategy**: Majority vote across the three sources → binary `hard` label. Agreement rate across sources → `soft` label (used for uncertainty-aware weighting).

**Key weaknesses**:
- GLAD-S2 blind to cloud-covered pixels (entire year lost in cloudy regions)
- GLAD-L has annual temporal resolution (can't detect within-year events precisely)
- RADD misses deforestation in flat, low-backscatter terrain (ambiguous with forest)
- Three sources can **actively disagree** on the same pixel

### 1.3 Split

- **Training tiles**: 16 tiles covering humid tropical forest regions
- **Test tiles**: Held-out tiles in **different geographic regions** — the primary generalization challenge
- **Validation**: 3 fixed tiles (`18NXH_6_8`, `48PXC_7_7`, `48QVE_3_0`) spanning diverse forest types and positive rates

## 2. Feature Engineering

### 2.1 Cache System (v3)

To avoid recomputing expensive reprojections and composites repeatedly, all derived features are cached as `.npz` files under `cache/train/<tile_id>.npz` and `cache/test/<tile_id>.npz`.

**Cache schema** (per tile, per year):
```
series: (T=6, C=68, H, W)   # T years × 68 channels
    channels 0–63  : AEF embeddings (raw, no normalization at cache time)
    channels 64–65 : S2 NDVI, NBR (annual cloud-masked composite)
    channels 66–67 : S1 VV ASC, VV DESC (annual median, dB)
```

### 2.2 Runtime Normalization (added after S1 integration)

Raw dB values (−15 to 0) have very different scale from AEF embeddings (roughly unit-normal). Mixing these without normalization causes the first conv layer to be dominated by the high-magnitude S1 channels.

**Fix**: per-channel z-score normalization applied **at dataset load time** using stats computed from all 16 train tiles:

```
stats computed for each channel separately:
  AEF ch 0–63 : stats from all pixels (AEF is always valid)
  S2 ch 64–65 : stats from valid (non-zero-filled) pixels only
  S1 ch 66–67 : stats from valid (non-zero-filled) pixels only
```

**Key stats**:
- AEF ch0: mean=+0.021, std=0.071
- S2 NDVI: mean=+0.697, std=0.165 (n=180M valid pixels)
- S1 ASC: mean=−7.539, std=1.621 (n=51M valid pixels)
- S1 DESC: mean=−7.124, std=1.598 (n=81M valid pixels)

Stats saved to `checkpoints/channel_stats.json` and loaded lazily at first dataset access.

### 2.3 Modality Validity Masks

Zero-fill is used to represent missing data in the cache (no observation = all zeros). This is **ambiguous** — a pixel could be zero because it has no data, or because the land truly has zero backscatter/NDVI. Feeding zero-filled cells as if they were valid observations confuses the model.

**Fix**: Derive 3 binary validity masks at load time from the cached features:

```python
s2_valid   = |NDVI| + |NBR|  > 1e-6   # (H, W) bool
s1_asc     = |VV_ASC|         > 1e-6
s1_desc    = |VV_DESC|        > 1e-6
```

After z-score normalization, any channel for which `valid=False` is explicitly zeroed out:

```python
norm[64:66] *= s2_valid       # zero out S2 where no data
norm[66:67] *= s1_asc_valid   # zero out S1 ASC where no data
norm[67:68] *= s1_desc_valid  # zero out S1 DESC where no data
```

**Final 71-channel layout**:

```
channels  0–63 : AEF embeddings (z-scored)
channels 64–65 : S2 NDVI + NBR (z-scored, zeroed where invalid)
channels 66–67 : S1 VV ASC + DESC (z-scored, zeroed where invalid)
channels 68–70 : 3 binary validity masks (s2_valid, s1_asc_valid, s1_desc_valid)
```

The validity masks allow the model to learn "no data here" explicitly and not confuse it with "flat signal."

## 3. Model Architecture

### 3.1 Siamese Change-Detection U-Net

**Idea**: Treat deforestation detection as a change detection problem. Take two annual AEF snapshots (pre-2020 baseline vs post-2025 latest) and find what changed.

**Architecture**:
- Two identical encoder branches (weight-shared), one for the pre-deforestation year and one for the current year
- At each decoder scale, fuse: `concat([post_features, |post_features − pre_features|])` — the absolute difference highlights change pixels
- 4-layer encoder + symmetric 4-layer decoder (standard U-Net skip connections)
- Base channels: 32 → 64 → 128 → 256 (4× multiplier)
- **~0.5M parameters** — deliberately small to avoid overfitting on 16 training tiles

**Input**: (2, 71, H, W) — pre and post stacked; uses only 2 of the T=6 available years.

**Limitation**: Ignores the trajectory between years. Misses multi-step deforestation events where neither endpoint fully triggers the change signal.

### 3.2 Temporal Change-Detection U-Net

**Idea**: Use all 6 years of AEF simultaneously and let the model reason about the full temporal trajectory.

**Input**: (T=6, 71, H, W) — entire annual stack from 2020 to 2025.

**Temporal fusion** (applied at each encoder scale to the T feature maps):

```python
# f[0]: 2020 baseline features, f[1..T-1]: subsequent years
last   = f[T-1]                             # latest snapshot
max_d  = max over t≥1 of |f[t] - f[0]|    # peak deviation from baseline
mean_d = mean over t≥1 of |f[t] - f[0]|   # sustained change signal

fused = concat([last, max_d, mean_d])       # 3× channel expansion at each scale
```

- `last`: encodes "what's there now" (current land cover type)
- `max_d`: captures the single worst deviation — good for detecting brief but large changes
- `mean_d`: captures sustained/permanent changes — good for distinguishing real deforestation from seasonal fluctuation

After fusion the decoder runs identically to the siamese model. This model can detect gradual degradation that the siamese model misses by only looking at endpoints.

**Parameters**: ~0.5M (same capacity as siamese, but sees richer temporal signal).

### 3.3 Clay Foundation Model (Secondary Approach)

**Idea**: Use a large pre-trained Vision Transformer (ViT-B) specialized for satellite imagery instead of training from scratch on AEF embeddings.

**Architecture**:
- **Clay v1.5**: ~300M parameter ViT-B trained on global S2 + S1 time series (public checkpoint)
- Encoder takes raw S2 bands (10 selected, skipping aerosol B01 and water vapor B09) as input patches
- Metadata conditioning: lat/lon encoded as `[sin(π·lat/180), cos(π·lat/180), sin(π·lon/180), cos(π·lon/180)]` injected into Clay encoder
- **Siamese wrapper**: run Clay encoder on pre-year and post-year separately (frozen or fine-tuned), extract spatial token grid (8× downsampled), fuse via `concat([post, |post − pre|])`
- Lightweight learned decoder head (4 conv upsampling layers) reduces to 1-channel deforestation map

**Training modes**:
- Phase 1: Clay encoder frozen, only segmentation head trained
- Phase 2: Full fine-tuning (much slower, ~1.2GB checkpoint)

**Why we tried it**: Foundation model pre-training encodes more global land cover knowledge than our 16-tile trained U-Net. However, Clay takes raw S2 bands (not AEF embeddings) and requires more compute.

**Outcome**: Clay matched but did not significantly outperform the lightweight AEF U-Net, and was far more expensive to train. The AEF embeddings were already encoding rich foundation model knowledge, making Clay largely redundant in this setup.

## 4. Training Pipeline

### 4.1 Loss Function

**BCETverskyLoss** — combination of two terms:

```python
loss = BCE(logits, labels, pos_weight=3.0)
     + Tversky(probs, labels, alpha=0.3, beta=0.7, smooth=1.0)
```

- **BCE with pos_weight=3**: upweights positive pixels to counteract class imbalance (~1–10% positives)
- **Tversky (α=0.3, β=0.7)**: α penalizes false positives, β penalizes false negatives; β>α means we care more about missing deforestation than about false alarms — appropriate given the recall-oriented leaderboard metric

When pseudo-labels are used, each pixel has a `weight ∈ {0, 1}`. The loss is masked: ignored pixels (weight=0) contribute zero gradient.

### 4.2 Data Loading & Augmentations

**Crop-based training**: Tiles are ~1004×998 pixels; we sample 256×256 crops each epoch.

**Positive crop sampling** (probability=0.75): 75% of crops are guaranteed to contain at least one positive pixel. Without this, most random crops from sparse deforestation tiles contain zero positives and produce zero useful gradient.

**Crops per tile per epoch**: 32 (train tiles) + 16 (pseudo-labeled test tiles when using pseudo-labels).

**Augmentations** (applied to each crop):
- Random 90° rotation (×4 symmetries): label-preserving for all channels
- Random horizontal flip: label-preserving
- **Modality dropout** (independent, p=0.2 per modality):
  - 20% chance: zero out all S2 channels for entire time series → simulates complete cloud cover year
  - 20% chance: zero out S1 ASC channels → simulates missing orbit track
  - 20% chance: zero out S1 DESC channels
  - Teaches the model to rely on whichever modality is available at inference time

### 4.3 Optimizer & Schedule

```
Optimizer: AdamW (lr=1e-3, weight_decay=1e-4)
Scheduler: CosineAnnealingLR (T_max=epochs=60)
Gradient clip: global norm 1.0
Batch size: 16
```

### 4.4 Validation & Checkpointing

Inference on 3 fixed validation tiles uses **sliding-window ensembling**:
- Window: 512×512, overlap: 64 px (stride=448)
- Overlapping predictions blended by averaging → smooth boundaries
- **Test-time augmentation (TTA)**: All 8 D4 symmetries (rotations + flips), average probabilities → reduces prediction variance by ~15–20%

**Best checkpoint**: saved on macro-average F1 across the 3 validation tiles.

**Threshold sweep**: After training, sweep threshold from 0.10 to 0.90 in steps of 0.02, pick the threshold maximizing macro F1 on validation.

## 5. Handling Noisy Labels

### 5.1 Multi-Source Fusion

Three independent alert systems (GLAD-S2, GLAD-L, RADD) are combined via **majority vote**. Pixels where all three agree are high-confidence; pixels where only one fires are low-confidence.

Benefits:
- RADD catches deforestation in cloudy years where GLAD-S2 is blind
- GLAD-S2 catches subtle optical changes RADD misses in low-contrast terrain
- GLAD-L provides an annual sanity check

### 5.2 Pseudo-Labels v1 (S2-only ensemble)

After initial training on noisy train-tile labels, generate **pseudo-labels on test tiles** by:
1. Running two independently trained S2-only models (siamese + temporal) on each test tile with TTA
2. Averaging their probabilities → ensemble prediction
3. Applying agreement-based thresholding:
   - **Positive**: both models ≥ 0.80 AND |prob_siamese − prob_temporal| ≤ 0.30
   - **Negative**: both models ≤ 0.20 AND agreement
   - **Ignore**: everything else (disagreement, mid-confidence)
4. Ignore pixels (weight=0) are masked out of loss during pseudo-label training

This is **conservative**: only the most confident, mutually agreed pixels become pseudo-labels. All uncertain pixels are simply skipped.

**Flaw discovered**: Because both teachers are S2-only, any deforestation event visible **only in radar (S1)** — common in cloud-covered tropical regions — was assigned negative pseudo-label. This actively punished the S2+S1 model at exactly the pixels where S1 should add value.

### 5.3 Pseudo-Labels v2 (Mixed-modality ensemble)

**Fix**: Use one S2-only teacher and one S2+S1 teacher. Relaxed agreement threshold allows single-modality detections to fall into the "ignore" zone (not negative), so the model is not punished for S1-only predictions.

```
Teacher 1: temporal_s2_pseudo_v2_best.pt       (S2-only)
Teacher 2: temporal_s2s1_norm_v1_best.pt       (S2+S1, z-scored, masked)

Rules (pixel-wise):
  Positive : p_s2 ≥ 0.60 AND p_s2s1 ≥ 0.60 AND |p_s2 − p_s2s1| ≤ 0.30
  Negative : p_s2 ≤ 0.20 AND p_s2s1 ≤ 0.20 AND agreement
  Ignore   : everything else
```

**Result**:
- v1: pos=1.67%, neg=95.87%, ignore=2.46%
- v2: pos=2.31%, neg=93.04%, ignore=4.66%

The increase in ignore pixels (from 2.5% to 4.7%) reflects pixels where only S1 detected a change — now correctly left unlabeled rather than forced to negative.

## 6. Evolution of Approaches

### Step 1: Baseline (AEF-only Siamese)
- Input: 64-channel AEF only, no S2/S1 features
- Simple siamese: pre vs post
- Noisy labels only
- Result: established working pipeline

### Step 2: S2 Features Added (Siamese v2 + Temporal v1)
- Added NDVI + NBR channels (66-ch input)
- Trained temporal model alongside siamese
- Ensemble (average) of both at inference
- Pseudo-labels v1 generated from S2 siamese + S2 temporal ensemble
- Retrain with pseudo-labels: **best val F1 ≈ 0.74**

### Step 3: Lower-Threshold Submission Sweep
- Observed: leaderboard IoU kept improving as threshold decreased
- Swept thr=0.05, 0.10, 0.15 → thr=0.05 was degenerate (single tile-wide polygon)
- thr=0.10: 37–72% positive pixel rate per tile → merging real/noise regions
- thr=0.15: stable, 627 polygons submitted

### Step 4: Clay Foundation Model
- Integrated Clay v1.5 ViT-B as alternative backbone
- Required raw S2 bands → separate data pipeline
- Added lat/lon metadata conditioning
- Outcome: competitive but not better than lightweight AEF U-Net; far more compute

### Step 5: S1 Integration (Proper)
Three problems with naive S1 integration (before this step):
1. Raw dB values (−15 to 0) vs AEF embeddings (unit-normal) → first conv dominated by S1 scale
2. Zero-fill ambiguous without validity mask → model learned wrong association
3. Pseudo-labels from S2-only teachers punished S1-only detections

**Solution implemented**:
- Per-channel z-score normalization (computed from valid pixels only)
- Explicit validity masks (channels 68–70)
- Modality dropout (p=0.2 per modality)
- 71-channel input

**Result**: `temporal_s2s1_norm_v1_best.pt` — val F1=0.743, IoU=0.597; leaderboard Union IoU=40.29%

### Step 6: Pseudo-Labels v2 + Final Retrain
- Generated v2 pseudo-labels using S2-only + S2+S1 ensemble
- Retrained: `temporal_s2s1_norm_pseudo_v1_best.pt`
- **Val F1=0.763, val IoU=0.622** (best checkpoint)
- Val-optimal threshold shifted 0.54 → 0.42 (pseudo-labels sharpened prob distribution)
- Multiple threshold submissions generated: thr015–thr040

## 7. Submission Pipeline

### 7.1 Inference
1. Load best checkpoint
2. Run sliding-window TTA inference on each test tile
3. Cache raw probability maps to `.npy` (for pseudo-label re-use without re-inference)

### 7.2 Polygonization
```python
submission_utils.raster_to_geojson(
    raster,        # binary (H, W) uint8
    transform,     # affine transform from rasterio
    crs,           # tile CRS
    min_area_ha=0.5  # filter < 0.5 hectare polygons
)
```
- Vectorizes binary raster to polygon/multipolygon (8-connectivity)
- Reprojects to EPSG:4326
- Applies minimum area filter (removes noise specks)

### 7.3 Per-Polygon Timestamp
Each polygon gets a `time_step` field estimated from NDVI drop analysis: find the year when NDVI dropped most steeply within the polygon footprint. ~99.4% of polygons receive a valid time_step.

## 10. Key Lessons

1. **Foundation embeddings reduce the model size requirement**: With 64-D AEF embeddings encoding global land cover priors, a 0.5M-parameter U-Net outperformed larger models trained on raw bands.

2. **Validity masks matter as much as the data**: Without explicit masks for missing modalities, zero-fill creates a confounding signal that the model partially learns but can't generalize from.

3. **Pseudo-label teacher quality determines what the student can learn**: S2-only teachers impose an S2-only ceiling. The student model cannot learn to use S1 if every S1-only positive is labeled as negative by the teachers.

4. **Threshold is a model decision, not an afterthought**: The optimal threshold shifted substantially between runs (0.54 → 0.42). Sweeping it on held-out validation data recovers significant IoU that would be lost with a fixed threshold.

5. **Modality dropout forces multi-modal robustness**: Without dropout, the model relied on S2 when available and ignored S1. With 20% per-modality dropout, it learned to use whichever modality has signal.

6. **Conservative pseudo-labels beat aggressive ones**: Ignoring uncertain pixels (weight=0) consistently outperformed including them. The loss function should never receive a gradient from a pixel the teacher is not confident about.
